# Ryser logo

`ryser-logo.png` is the original artwork supplied by the project owner on
16 October 2026. Preserve its proportions, complete clock face, lettering,
colours and background. Flutter displays this file directly.

Run `powershell -NoProfile -File tool/generate_store_artwork.ps1` from the
repository to regenerate the Android launcher sizes and store artwork.
The original green R remains the Android launcher icon (including its adaptive
and monochrome variants) and store app icon. The supplied clock artwork appears
inside the app and on the feature graphic.
